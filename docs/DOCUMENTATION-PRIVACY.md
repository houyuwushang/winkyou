# 公开文档隐私边界

本规则覆盖根目录 Markdown、全部 `docs/`（包括 archive/templates）、`deploy/`、`scripts/` 与 `.github/`，
没有历史目录或整文件豁免。另有窄规则扫描 `cmd/`、`pkg/`、`internal/`、`test/` 的所有 Go 源码与测试注释。
面向公开阅读保留架构、协议、计数、事故、暂停与 NO-GO 事实；不保留某次部署的地址、
登录身份、个人目录、公钥、SSH 指纹、设备标识或访问材料。

## 占位符与合成示例

连接目标、SSH 目的地、主机别名、目录和联系渠道使用 `<PLACEHOLDER>` 形式。
历史记录中的占位符只保留文档内的角色/相等关系，不是仍可使用的端点；不得直接执行这些命令。
历史计数和协议时限不因脱敏修改。公开技术资料链接与仓库内源文件路径不是部署目标。

允许的地址语义逐项列举如下；不是将某份历史材料整体加入白名单：

| 类别 | 明确允许值 | 限制 |
| --- | --- | --- |
| IPv4 文档网段 | 192.0.2.0/24、198.51.100.0/24、203.0.113.0/24 | 仅合成示例，不是现场授权 |
| IPv6 文档网段 | 2001:db8::/32 | 同上；不允许 zone/interface 标识 |
| 回环 | 127.0.0.0/8、::1 | 仅表示本地隔离机制，不表示某人的设备 |
| wildcard | 0.0.0.0、:: | 只表示绑定语义，不是任意目标权限 |
| RFC1918 合成主机 | 10.0.0.1、10.0.0.2 | 本规则专门定义的示例；其他私网主机默认拒绝 |
| RFC1918 合成网段 | 10.0.0.0/24 | 仅此精确前缀，不放行整个私网范围 |
| 标准地址分类前缀 | 100.64.0.0/10、198.18.0.0/15、128.0.0.0/1 | 仅精确前缀语法，不允许其任意主机作为端点 |

新增示例应优先使用文档网段或占位符。不能因为一个值属于私网、shared-address 或 benchmark
范围，就声称它是合成数据。历史现场观测即使恰好与上述合成示例同值，也仍须替换为占位符，
不能借示例白名单重新解释原始证据。本次已按此规则替换历史记录中的网关值。
原始现场记录留在仓库外，不复制到 PR、评论或 CI artifact。
C1c 的唯一约定实例位置为 `~/.winkyou-field/c1c.json`；本规则不创建、读取或签发该文件。

## 精确语法例外

扫描器按单个 token 判断以下非身份语法，不能因同一行出现例外就放过该行其它值：

- PowerShell 数组、哈希表和 here-string 分隔符；u32 操作符的独立代码 token。
- 本仓库文档的固定 systemd 服务模板与纯数字 instance，不放行任意用户名/主机名。
- 明确的公共依赖版本引用、仓库基线引用，以及列举过的稳定错误类/阶段组合。
- 公开资料的 Markdown 引用目标；禁止 URL user-info，把传输地址伪装成引用也不放行。
- 斜杠连接的环境分类文字不是绝对用户目录；真正位于路径边界的用户目录仍拒绝。

完整规则与正负例由 `internal/architecture/documentation_privacy_test.go` 固定。
Go 源码规则由 `internal/architecture/source_privacy_test.go` 固定；允许私网、ULA、link-local、
shared/benchmark 分类夹具和明确的公共解析器合成例子，但拒绝其它公网地址、登录目的地、跳板和密钥材料。
维护者本批明确要求保留的 `IPV4_12` 作为合成示例列入两道门的正例；不因扫描扩围改变它。
维护者另行批准 quickstart 现有 `WINK_NETWORK_CIDR` 默认值的完整 CIDR token：仅精确网段配置
语法可用，不放行裸地址、网段内主机、其他掩码或伪装后缀；配置本身保持不变，正负例固定该边界。
脚本语言操作符与字段插值按单个 token 判断；同一行额外身份不得借语法例外逃过检查。
测试报告仅包含仓库相对文件名、行号与错误类，不回显匹配到的值。
新增模板、子目录和同一行混合合法/非法值均有回归，不能通过调整工作目录绕开扫描。

## 审查与保留范围

自动门只能发现已定义的语法，不能证明任意自然语言里绝无身份信息。发布前仍需人工复核：
主机/设备代号、域名、账号、密钥、命令参数、图片和附件是否泄露真实部署信息。
身份和数据不明时改成占位符，不扩充白名单求绿。
